¿De qué trata la actividad?
En esta práctica aprendí a usar herramientas de control de versiones que se usan mucho en la industria, como Git y GitHub. La idea principal fue organizar un repositorio propio, subir mis documentos y practicar los comandos básicos para llevar un buen registro de los cambios
 ¿Cómo hice el trabajo?
1. Creación de cuenta y repositorio:Lo primero fue entrar a GitHub y crear mi repositorio público llamado `actividad-2-ciencia-de-datos`
2. Instalación y configuración de Git: Me aseguré de tener Git instalado en mi computador y configuré mi nombre y correo con los comandos de configuración global
3. Clonarlo en el computador Usé el comando `git clone` para descargar el repositorio a mi equipo y poder trabajar localmente
4. Hacer los documentos:Consulté la documentación oficial del libro *Pro Git* para redactar los resúmenes por capítulos y los exporté a PDF.
5. Subir los avances: Fui aplicando el ciclo de Git (`git add`, `git commit` con mensajes explicando cada cambio y `git push origin main`) para subir cada PDF y que quedara el registro de los commits.
